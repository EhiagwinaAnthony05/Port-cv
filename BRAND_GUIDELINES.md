# EHINOVA Brand Guidelines

## Brand Direction
EHINOVA presents clarity and control. The visual system should feel calm, intelligent, and intentional.

## Color Palette
- Primary Black: `#0B0F10`
- Insight Teal: `#0F8B8D`
- White: `#FFFFFF`
- Soft Grey (UI border/surfaces): `#DDE5E8`
- Neutral Grey (supporting text): `#6F7F87`

## Color Usage Rules
- Use black as the foundational color for structure, headings, and key UI anchors.
- Use teal selectively for highlights, key emphasis, active states, and selection.
- Use white and soft grey to create breathing room and readability.
- Avoid overusing teal; it should guide attention, not dominate layouts.

## Typography
### Primary Type
- Typeface: `Sage Grotesk`
- Role: headings, navigation, key statements, brand-led messaging.
- Tone: clear, strategic, authoritative.

### Secondary Type
- Typeface: `Poppins`
- Role: body text, paragraphs, captions, and long-form content.
- Tone: approachable, warm, readable.

## Implementation Notes
- CSS token source: `src/styles/base.css`
- Main font import entry: `src/index.css`
- If `Sage Grotesk` webfont is not bundled yet, keep local fallback to `Poppins` until licensed font files are added.
